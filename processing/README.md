## Directory Layout

- **LaTeX Books & Source Files**:
  Contains LaTeX source documents (`.tex`), custom class files (`superuserguide.cls`), configuration (`latexmkrc`), and structural subdirectories (`chapters/`, `frontmatter/`, `notation/`, `bib/`, `appendices/`, `book1-latex-source/`, `superuser-guide-to-latex/`).
- **Transcripts & Media Bundles**:
  Each transcript subject is paired with its audio recording (`.mp3`) and structured transcript files in multiple formats (`.json`, `.txt`, `.srt`, `.vtt`, `.tsv`), alongside compiled transcript PDFs. Includes:
  - *Al-Biruni and the cost of objective truth*
  - *Engineering Your LaTeX Document as Code*
  - *Steering the state with cybernetics*
  - *The 250-year struggle to ground AI*
  - *The Structural Grammar of Vim*
- **Scripts & Assets**:
  - `fix_transcription_errors.sh`: Transcription post-processing and text normalization script.
  - Media & graphics: `infographic.png`, `marble.png`, `cover.pdf`.
